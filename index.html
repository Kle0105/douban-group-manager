使用说明
本地资料整理版 · GitHub Pages 部署
本版本的定位：用于管理本人或已获明确授权账号的公开资料。它不是豆瓣自动爬虫，不会自动查询成员列表，也不会绕过登录、隐私或访问限制。

1. 创建账号档案

在「总览」输入用户 ID 和昵称，并确认账号授权范围，然后保存档案。

2. 添加小组资料

进入「小组记录」，录入小组名称、ID、主页链接、状态和可核验的证据链接。状态为「已人工核验」的记录才会进入 Excel。

3. 本地保存

数据保存在当前浏览器的 localStorage 中。清理浏览器数据、换浏览器或换设备可能导致记录不可用，请定期导出 JSON 备份。

4. 导出 Excel

点击「导出已核验 Excel」，只导出状态为「已人工核验」的记录。首次导出需要联网加载 Excel 文件生成组件。

5. 发布到 GitHub Pages

将项目中的 index.html 上传到 GitHub 仓库，在 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 /(root)，保存后等待生成公开网址。

隐私提醒：GitHub Pages 的网页是公开的，但本工具不会把本地数据上传到仓库。不要在公共或他人共用设备上保存敏感资料。
